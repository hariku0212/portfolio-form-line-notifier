# Googleフォーム → LINE Bot 即時通知システム

> Googleフォームへの回答を、LINE Messaging API 経由でリアルタイムに通知するGASツール。  
> LINE Notify終了（2025年3月）後の実用的な代替手段として設計。

---

## 機能

- Googleフォームへの回答送信を検知して **即座にLINEへプッシュ通知**
- 質問と回答を見やすく整形してメッセージを組み立て
- スプレッドシートへのリンクを通知に自動添付
- エラー発生時は管理者メールへ自動通知
- テスト送信関数で簡単に動作確認が可能

---

## 技術スタック

| 分類 | 技術・サービス |
|------|-------------|
| スクリプト | Google Apps Script (V8 Runtime) |
| トリガー | スプレッドシート フォーム送信時トリガー |
| 外部API | LINE Messaging API v2（Push Message） |
| 認証情報管理 | PropertiesService（スクリプトプロパティ） |
| ログ | Cloud Logging (Stackdriver) |

## セットアップ手順

### 前提条件

- Googleアカウント
- LINE Developersアカウント（無料）
- LINE Messaging API チャンネルの作成済み

### 1. LINE Messaging APIの準備

1. [LINE Developers Console](https://developers.line.biz/) にアクセス
2. 「Messaging API」チャンネルを作成
3. 「チャンネルアクセストークン（長期）」を発行・コピー
4. 通知を送りたいユーザーのUser ID、またはグループIDを確認

### 2. Googleフォームとスプレッドシートの準備

1. Googleフォームを作成（または既存のフォームを使用）
2. フォームの回答先スプレッドシートを作成/連携
3. スプレッドシートを開き、「拡張機能」→「Apps Script」を選択

### 3. スクリプトの設置

1. `Code.gs` の内容をGASエディタに貼り付け
2. `appsscript.json` の内容をマニフェストに反映（「プロジェクトの設定」でマニフェスト表示を有効化）

### 4. スクリプトプロパティの設定

GASエディタの「プロジェクトの設定」→「スクリプトプロパティ」で以下を追加:

| プロパティ名 | 値 |
|------------|-----|
| `LINE_CHANNEL_ACCESS_TOKEN` | 手順1で取得したアクセストークン |
| `LINE_TARGET_ID` | 通知先のユーザーID または グループID |

### 5. トリガーの設定

GASエディタで `setupTrigger` 関数を実行（初回のみ）。  
または手動でトリガーを設定:「トリガーを追加」→ `onFormSubmit` → フォーム送信時

### 6. 動作確認

`testSendLine` 関数を実行し、LINEにテストメッセージが届くことを確認。

## こだわりポイント

### セキュリティ
APIトークンをソースコードに直書きせず、`PropertiesService` で一元管理。  
コードをGitHubに公開しても認証情報が漏洩しない設計。

### エラーハンドリング
LINE API呼び出し失敗時にHTTPステータスと本文をログ記録。  
管理者メール通知でサイレント障害を防止。

### 移植性
フォームの質問が変わっても `buildLineMessage` が動的に整形するため、  
コードを変更せず複数のフォームに展開できる。

### LINE Notify廃止対応
2025年3月31日にLINE Notifyが終了。本ツールはMessaging APIを直接呼び出すため  
長期安定運用が可能。既存のLINE Notify連携からの移行先としても最適。
